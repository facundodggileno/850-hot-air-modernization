# Material académico (19 de noviembre de 2026)

Se incluyen **carpeta de campo** en Word editable y PDF y **presentación** en PowerPoint editable y PDF. En los documentos de esta publicación se han retirado las referencias a agregar sensores de caudal como propuesta futura.

Los documentos describen el prototipo, su evolución y sus límites; la V2.0.5 requiere validación física completa. El código fuente y el esquema se mantienen en sus carpetas principales, por lo que estas piezas no reemplazan la documentación técnica vigente.

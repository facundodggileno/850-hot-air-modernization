# Hardware

This folder will contain the electrical design of the modernization.

Planned contents:

- Original-station measurements and reverse-engineering notes.
- Wiring diagrams.
- Controller schematic.
- Heater control stage.
- Pump / airflow control stage.
- Temperature sensing interface.
- Stand sensor interface.
- PCB files if a custom board is developed.

No hardware files should be considered final until they are explicitly marked as tested.
